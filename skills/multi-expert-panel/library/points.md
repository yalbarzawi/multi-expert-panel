# Diskussionspunkte

Hauptpunkte (Agenda), aus denen das Panel vorschlägt, wenn der Nutzer keine genannt hat. Jeder Punkt hat eine Leitfrage. Die Leitfrage immer auf den Fall zuschneiden. Welche Punkte zu welchem Thema passen, steht in den Themenpaketen unter `topics/`.

## Allgemeine Punkte

### Entscheidung (Ideen, Projekte, Anschaffungen)
| Punkt | Leitfrage |
|---|---|
| Problem und Bedarf | Wie stark und wie oft schmerzt das Problem? Wer sucht heute aktiv nach einer Lösung? |
| Zielgruppen | Wer ist der erste zahlende Kunde, wer kommt später? Wie groß ist jede Gruppe? |
| Ist-Zustand / Marktlage | Wie lösen die Leute das Problem heute? Was hat sich am Markt zuletzt geändert? |
| Marktgröße und Anteil | Wie viele potenzielle Kunden gibt es, welcher Anteil ist realistisch erreichbar? |
| Konkurrenz und Abgrenzung | Wer bietet das schon an, kostenlos oder bezahlt? Was ist schwer zu kopieren? |
| Produkt / MVP | Was ist der kleinste Umfang, der das Kernproblem löst? Was kommt später? |
| Geschäftsmodell und Preis | Wer zahlt wie viel, einmalig oder laufend? Warum bleibt der Kunde? |
| Finanzierung und Förderung | Eigenkapital, Kredit, Förderprogramme, Investor: was ist realistisch, mit welchen Bedingungen? |
| Kosten, Break-even, Verlust | Laufende Kosten, Zeitaufwand, ab wann trägt es sich, was ist im schlimmsten Fall verloren? |
| Vertrieb und Marketing | Über welchen Kanal kommen die ersten 10, 100 Kunden? |
| Recht und Risiken | Haftung, Lizenzen, Markenrecht, DSGVO, Missbrauch |
| Team und Zeit | Wer baut, wer verkauft? Passt das neben Job, Familie, Agentur? |
| Skalierung und Zukunft | Was passiert bei 10-facher Nachfrage? Wo steht das in 3 Jahren? |
| Ausstieg / Plan B | Woran merkt man früh, dass es nicht läuft, und was bleibt dann übrig? |

### Analyse (Texte, Code, Dokumente, Websites)
| Punkt | Leitfrage |
|---|---|
| Erster Eindruck | Was bleibt nach 30 Sekunden hängen? |
| Ziel und Zielpublikum | Erreicht der Inhalt das Ziel bei genau diesen Lesern / Nutzern? |
| Inhalt und Belege | Stimmen die Aussagen, sind sie belegt und konkret? |
| Struktur und Lesbarkeit | Findet man sich zurecht, ist die Reihenfolge logisch? |
| Form und Pflichtangaben | Fehlt etwas, das verlangt oder üblich ist? |
| Risiken und Fehler | Was kann schiefgehen, rechtlich, technisch, beim Leser? |
| Was jetzt? | Welche Änderungen bringen am meisten? |

## Welche Rollen zu welchem Punkt passen

Hat der Nutzer Punkte gewählt, aber kein Panel, oder fehlt für einen Punkt eine Stimme: aus dieser Tabelle ergänzen. Jeder gewählte Punkt sollte mindestens eine Rolle haben, die ihn fachlich trägt.

| Punkt | Rollen (siehe roles/) |
|---|---|
| Problem und Bedarf | Zielkunde, Endnutzer, Marktforscher, Researcher |
| Zielgruppen | Marktforscher, Zielkunde, Performance-Marketer, Markenstratege |
| Ist-Zustand / Marktlage | Researcher, Branchenveteran, Volkswirt, Faktenprüfer |
| Marktgröße und Anteil | Volkswirt, Statistiker, Datenanalyst, Investor |
| Konkurrenz und Abgrenzung | Wettbewerbsanalyst, Konkurrent, Branchenveteran |
| Produkt / MVP | Produktmanager, Architekt, Pragmatiker, Endnutzer |
| Geschäftsmodell und Preis | Finanzanalyst, Vertriebsleiter, Zielkunde |
| Finanzierung und Förderung | Gründungsberater (IHK), Bankberater, Investor, Finanzanalyst |
| Kosten, Break-even, Verlust | Zahlenmensch, Controller, Szenario-Planer, Mathematiker |
| Vertrieb und Marketing | Performance-Marketer, Vertriebsleiter, Social-Media-Manager |
| Recht und Risiken | passender Fachanwalt, Datenschutzbeauftragter, Risikoanalyst, Red Team |
| Team und Zeit | Projektmanager, Partner / Familie, Zukunfts-Ich |
| Skalierung und Zukunft | Trendforscher, Architekt, Seriengründer |
| Argumentation (bei Analysen) | Logiker, Faktenprüfer, Wissenschaftler |

## Wie vorschlagen

- **4–6 Punkte** vorschlagen, davon die ⭐ zuerst. Mit Frage-Werkzeug (höchstens 4 Optionen pro Frage) bei mehr als 4 Punkten auf zwei Fragen verteilen.
- Zu jedem Punkt ein Halbsatz, warum er **in diesem Fall** wichtig ist. „Konkurrenz“ allein hilft nicht, „Konkurrenz: Brandfetch hat schon eine kostenlose Logo-API“ schon.
- Hat der Nutzer Fragen gestellt („Bringt das Geld? Gibt es Förderung?“), werden sie automatisch zu Punkten.
- Die Punkte werden zu den Gesprächsrunden (Stil C, F) bzw. zur Gliederung (Stil A, D). Im Fazit kommt jeder gewählte Punkt mindestens einmal vor.
