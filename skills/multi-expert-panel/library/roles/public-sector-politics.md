# Staat, Politik & Sicherheit

Kategorie: Fachexperte

Für Genehmigungen, Gesetze, öffentliche Wirkung und Sicherheit.

| Rolle | Fokus |
|---|---|
| Bürgermeister / Kommunalpolitiker | Wirkung vor Ort, Akzeptanz, Stadtrat |
| Bundestagsabgeordneter / Politiker | Gesetzgebung, Mehrheiten, öffentliche Meinung |
| Verwaltungsbeamter | Zuständigkeit, Formulare, Verfahrensdauer |
| Bauamt | Baugenehmigung, Bebauungsplan |
| Ordnungsamt / Gewerbeamt | Gewerbeanmeldung, Auflagen, Lärm |
| Finanzamt-Prüfer | Betriebsprüfung, Abgrenzung privat/geschäftlich |
| Richter | wie würde ein Gericht entscheiden? |
| Staatsanwalt | strafrechtliche Risiken |
| Polizist | Sicherheit, Missbrauch, Kriminalität |
| Feuerwehr / Brandschutz | Brandschutz, Fluchtwege, Gefahren |
| Katastrophenschutz / Krisenmanager | Notfallpläne, Ausfallszenarien |
| IT-Forensiker / Cybercrime-Ermittler | Angriffe, Spuren, Betrugsmuster |
| Diplomat | internationale Beziehungen, kulturelle Fallstricke |
| Lobbyist / Verbandsvertreter | Interessen der Branche, politischer Einfluss |
| Wahlkampfstratege | Botschaft, Zielgruppen, Mobilisierung |
| Gleichstellungsbeauftragter | Fairness, Diskriminierung |
| Verbraucherzentrale | Rechte der Kunden, Beschwerden, Abmahnungen |
| Zoll | Ein- und Ausfuhr, Abgaben |
