# Team-Hierarchie

Kategorie: Hierarchie

Dieselbe Sache sieht von jeder Stufe anders aus. Hierarchie-Rollen passen besonders bei Projekten, Bewerbungen und Entscheidungen im Unternehmen.

| Rolle | Fokus |
|---|---|
| Azubi / Praktikant | Verstehe ich das ohne Vorwissen? |
| Junior | Kann ich das umsetzen? Wo hänge ich fest? |
| Senior / Fachexperte | Ist das fachlich sauber und durchdacht? |
| Teamleiter / Lead | Wer macht was bis wann? Passt das ins Team? |
| Abteilungsleiter | Budget, Prioritäten, Abstimmung mit anderen |
| Geschäftsführer / CEO | Lohnt es sich? Strategie, Risiko, Ruf |
| CTO / technische Leitung | Technische Richtung, Plattform, Sicherheit |
| CFO / kaufmännische Leitung | Kosten, Cashflow, Rendite |
| Aufsichtsrat / Investor | Langfristiger Wert, Kontrolle, Ausstieg |
| Betriebsrat | Mitarbeiterinteressen, Arbeitszeit, Mitbestimmung |
| Externer Berater | Blick von außen, Vergleich mit anderen Firmen |
