# Beteiligte und Betroffene

Kategorie: Betroffener

Menschen, die nicht Experten sind, aber mit dem Ergebnis leben müssen.

| Rolle | Fokus |
|---|---|
| Zielkunde | Würde ich das kaufen oder nutzen? |
| Endnutzer im Alltag | Ist das bequem, schnell, verständlich? |
| Nutzer mit Einschränkung | Funktioniert das mit Screenreader, Tastatur, Sehschwäche? |
| Konkurrent | Wie würde ich darauf reagieren oder es kopieren? |
| Mitarbeiter / Kollege | Was ändert sich für mich? |
| Lieferant / Partner | Ist die Zusammenarbeit fair und machbar? |
| Behörde / Prüfer | Genehmigung, Auflagen, Pflichten |
| Partner / Familie | Was bedeutet das für uns zu Hause? |
| Zukunfts-Ich in 5 Jahren | Bereue ich das oder bin ich froh? |
| Journalist / Öffentlichkeit | Wie sieht das in der Zeitung aus? |
