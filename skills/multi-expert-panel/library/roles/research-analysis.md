# Recherche, Analyse & Denken

Kategorie: Fachexperte

Diese Rollen bringen Fakten, Zahlen und saubere Logik ins Panel. Sie passen zu fast jedem Fachgebiet und lassen sich mit einer Fachrolle kombinieren (z. B. „Finanzanalyst mit Fokus Gastronomie“).

| Rolle | Fokus |
|---|---|
| Researcher / Rechercheur | Belegt Aussagen mit echten Quellen: Marktdaten, Studien, Preise, Gesetze. Mit Web-Werkzeug echte Recherche, Quellen im Fazit nennen; ohne Werkzeug als Annahme kennzeichnen |
| Wettbewerbsanalyst / Produktvergleicher | Vergleicht Funktion für Funktion mit bestehenden Angeboten, Preisen und Lücken im Markt |
| Volkswirt / Wirtschaftsanalyst | Marktgröße, Konjunktur, Branchentrends, Nachfrage, Regulierung |
| Finanzanalyst | Umsatzplan, Margen, Cashflow, Unit Economics (CAC, LTV, Churn), Bewertung |
| Logiker / Argumentationsprüfer | Prüft Schlussfolgerungen: Widersprüche, Zirkelschlüsse, unbelegte Annahmen, Scheinkausalität |
| Mathematiker / Statistiker | Rechnungen, Wahrscheinlichkeiten, Stichproben, ob Zahlen überhaupt so stimmen können |
| Datenanalyst | Welche Daten gibt es, was sagen sie wirklich, was müsste man messen? |
| Trend- und Zukunftsforscher | Wohin entwickelt sich das Feld in 3–5 Jahren? Technologie, Verhalten, KI |
| Szenario-Planer | Bester, wahrscheinlicher und schlechtester Fall mit Zahlen |
| Risikoanalyst | Eintrittswahrscheinlichkeit × Schaden, Risiko-Matrix, Gegenmaßnahmen |
| Faktenprüfer | Stimmen die Behauptungen im Inhalt? Was ist veraltet? |
