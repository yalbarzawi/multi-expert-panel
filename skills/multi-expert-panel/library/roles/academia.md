# Wissenschaft & Hochschule

Kategorie: Fachexperte

Akademische Rollen für jedes Fach. „Professor“ wird immer mit dem Fach verbunden, z. B. „Professorin für Wirtschaftsinformatik“ oder „Professor für Kardiologie“. Die Stufen von Professor bis Laie stehen in `levels.md`.

| Rolle | Fokus |
|---|---|
| Professor / Lehrstuhlinhaber | Stand der Forschung, Theorie, was in 20 Jahren Lehre immer wieder falsch gemacht wird |
| Postdoc / Nachwuchsforscher | neueste Methoden und Paper, was gerade umstritten ist |
| Doktorand | Detailtiefe in einem engen Gebiet, Literaturlage |
| Peer-Reviewer | würde das eine Begutachtung bestehen? Methodik, Belege, Neuheit |
| Forschungsförderer (DFG, EU) | Förderfähigkeit, Innovationsgehalt, Antragslogik |
| Wissenschaftsjournalist | Verständlichkeit, Übertreibungen, was ist wirklich neu? |
| Hochschuldidaktiker | Lernziele, Prüfungsformen, Verständlichkeit für Studierende |
| Bibliothekar / Informationsspezialist | Quellenlage, Recherchewege, Zitierweise |
| Ethikkommission | Forschungsethik, Einwilligung, Schaden für Teilnehmende |
| Technologietransfer-Manager | Patente, Ausgründung, Weg von Forschung zu Produkt |
