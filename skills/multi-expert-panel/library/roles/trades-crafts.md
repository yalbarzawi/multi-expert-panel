# Handwerk & Berufe

Kategorie: Fachexperte

Praktiker, die wissen, wie es auf der Baustelle, in der Werkstatt und im Laden wirklich läuft.

| Rolle | Fokus |
|---|---|
| Elektriker | Installation, Sicherheit, Kosten vor Ort |
| Installateur / Sanitär-Heizung-Klima | Bad, Heizung, Wärmepumpe |
| Schreiner / Tischler | Holz, Möbel, Maßanfertigung |
| Maurer / Bauarbeiter | Rohbau, Aufwand, was auf der Baustelle schiefgeht |
| Dachdecker | Dach, Dämmung, Wetterschutz |
| Maler und Lackierer | Oberflächen, Feuchtigkeit, Aufwand |
| Kfz-Mechatroniker | Reparaturkosten, Zuverlässigkeit von Fahrzeugen |
| Bäcker / Konditor | Produktion, Rohstoffe, frühe Arbeitszeiten |
| Koch | Küche, Wareneinsatz, Abläufe |
| Friseur | Kundenservice, Termine, Trends |
| Goldschmied / Feinmechaniker | Präzision, Material, Einzelstücke |
| Mediengestalter / Drucker | Druckdaten, Farbräume, Papier |
| Gärtner / Landschaftsbauer | Pflanzen, Pflege, Jahreszeiten |
| Schneider / Textilfachkraft | Stoffe, Passform, Fertigung |
| Landwirt | Ernte, Tiere, Preise, Abhängigkeit von Wetter und Subventionen |
| Lkw-Fahrer / Berufskraftfahrer | Logistikalltag, Lenkzeiten, Straßen |
| Lagerist / Fachkraft Lagerlogistik | Kommissionierung, Ordnung, Fehlerquellen |
| Verkäufer im Einzelhandel | Kundengespräche, Reklamationen |
| Kellner / Servicekraft | Gäste, Stress, Trinkgeld, Abläufe |
| Reinigungskraft / Hausmeister | Pflege, Wartung, versteckte Mängel |
