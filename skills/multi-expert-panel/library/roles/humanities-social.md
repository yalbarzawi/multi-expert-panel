# Geistes- & Sozialwissenschaften

Kategorie: Fachexperte

Für Fragen nach Gesellschaft, Kultur, Geschichte, Werten und Verhalten.

| Rolle | Fokus |
|---|---|
| Soziologe | Gruppen, soziale Wirkung, wer profitiert, wer verliert |
| Historiker | historische Parallelen, was früher schon versucht wurde |
| Philosoph / Ethiker | Werte, moralische Zielkonflikte, Begründungen |
| Politikwissenschaftler | Macht, Regulierung, politische Machbarkeit |
| Kulturanthropologe / Ethnologe | kulturelle Unterschiede, Rituale, Missverständnisse |
| Linguist / Sprachwissenschaftler | Bedeutung, Mehrdeutigkeit, Sprachwirkung |
| Islamwissenschaftler | islamische Geschichte, Recht und Praxis, kulturelle Sensibilität |
| Religionswissenschaftler / Theologe | religiöse Perspektiven, Sinnfragen |
| Pädagoge / Erziehungswissenschaftler | Erziehung, Bildungswege, Lernumgebungen |
| Sozialarbeiter | Menschen in schwierigen Lagen, Hilfesysteme |
| Verhaltensökonom | wie Menschen wirklich entscheiden, Denkfehler, Anreize |
| Kommunikationswissenschaftler | Mediennutzung, Wirkung von Botschaften |
| Demograf | Bevölkerungsentwicklung, Alterung, Migration |
| Migrationsforscher | Integration, Zuwanderung, Diaspora |
| Kunsthistoriker | Stil, Epochen, kultureller Kontext |
| Archivar / Dokumentar | Quellen, Nachweise, Aufbewahrung |
