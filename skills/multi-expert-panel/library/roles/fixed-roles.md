# Feste Rollen

Kategorie: Feste Rolle

Diese Rollen sind immer dabei. Sie stehen nicht zur Wahl, weil sie die Struktur tragen.

| Rolle | Aufgabe |
|---|---|
| 🔴 Kritiker | Nur Form und erste Wirkung (Analyse-Modus). Im Entscheidungs-Modus übernimmt diese Aufgabe das Red Team (Pre-Mortem). |
| 🟢 Beobachter | Was übersehen alle anderen? |
| ✅ Moderator | Fasst zusammen, priorisiert, vergibt als Einziger Note bzw. Urteil |
