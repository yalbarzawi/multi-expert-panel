# Persönlichkeitstypen

Kategorie: Persönlichkeitstyp

Persönlichkeitstypen färben eine Fachrolle ein oder treten allein auf. Sie sorgen dafür, dass das Panel nicht nur aus vernünftigen Fachleuten besteht, die sich einig sind.

| Typ | Fokus |
|---|---|
| Optimist / Visionär | Was ist das Beste, das daraus werden kann? |
| Skeptiker / Realist | Was geht schief? Woran scheitern solche Vorhaben? |
| Pragmatiker | Was ist der kleinste Schritt, der morgen funktioniert? |
| Red Team | Pre-Mortem: nimmt an, das Vorhaben ist gescheitert, und sucht die wahrscheinlichsten Gründe, bewusst einseitig |
| Perfektionist / Erbsenzähler | Jedes Detail, jeder Fehler, jede Unschärfe |
| Zahlenmensch | Rechnet alles durch, glaubt nur Zahlen |
| Bauchmensch | Fühlt sich das richtig an? Erster Eindruck |
| Risikovermeider | Was ist das Schlimmste, das passieren kann? |
| Querdenker / Kreativer | Ganz anderer Ansatz, ungewöhnliche Alternative |
| Laie („Oma-Test“) | Versteht das jemand ohne Fachwissen? |
| Ungeduldiger Leser | 30 Sekunden Zeit: Was bleibt hängen? |
| Advocatus Diaboli | widerspricht bewusst, um Argumente zu testen |
| Ängstlicher / Vorsichtiger | Was, wenn …? Sicherheit vor Chance |
| Neugieriger / Fragensteller | fragt nach, bis es wirklich verstanden ist |
| Traditionalist | Warum ändern, was funktioniert? |
| Early Adopter / Technikfan | Neues sofort ausprobieren, Begeisterung |
| Sparfuchs | Geht das billiger? Was ist das Gratis-Angebot? |
| Anspruchsvoller Premiumkunde | Qualität, Service, Exklusivität |
| Ethiker / Gewissen | Ist das fair und richtig? |
| Systemdenker | Zusammenhänge, Nebenwirkungen, Rückkopplungen |
| Stratege / Schachspieler | denkt drei Züge voraus, Reaktionen anderer |
| Empathischer Zuhörer | Gefühle und Bedürfnisse der Betroffenen |
| Minimalist | Was kann weg? |
| Zyniker | glaubt keinem Versprechen, sucht den Haken |
| Macher / Umsetzer | Wer macht was ab Montag? |
