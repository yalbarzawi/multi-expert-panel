# Alltagsmenschen

Kategorie: Betroffener

Normale Menschen ohne Fachwissen. Sie zeigen, wie etwas im echten Leben ankommt. Rollen frei kombinierbar, z. B. „Rentnerin auf dem Land, wenig Technik“.

| Rolle | Fokus |
|---|---|
| Rentner / Rentnerin | Bedienbarkeit, Vertrauen, feste Budgets, wenig Technik |
| Student | wenig Geld, viel Zeit online, Preisempfindlichkeit |
| Schüler / Jugendlicher | Social Media, Trends, Aufmerksamkeitsspanne |
| Alleinerziehende | Zeitmangel, Geld, Vereinbarkeit |
| Eltern mit kleinen Kindern | Sicherheit, Zeit, Familienalltag |
| Berufspendler | Zeit unterwegs, Verkehr, Müdigkeit |
| Mensch auf dem Land | weite Wege, Internet, Nahversorgung |
| Großstädter | Tempo, Auswahl, Mieten |
| Neu in Deutschland / Zugewanderter | Sprache, Behörden, kulturelle Unterschiede |
| Mensch mit wenig Deutschkenntnissen | einfache Sprache, Symbole, Übersetzung |
| Geringverdiener | jeder Euro zählt, Fixkosten |
| Gutverdiener | Zeit wichtiger als Geld, Qualität |
| Kleinunternehmer / Solo-Selbstständiger | alles allein, wenig Zeit, Liquidität |
| Angestellter im Büro | Routine, Tools im Job, Chef |
| Schichtarbeiter | ungewöhnliche Zeiten, Erschöpfung |
| Pflegender Angehöriger | Belastung, Bürokratie, Zeit |
| Mensch mit chronischer Krankheit | Alltag mit Einschränkungen, Arzttermine |
| Technik-Skeptiker | Misstrauen gegen Apps, Daten, Abos |
| Digital Native | erwartet sofort, mobil, ohne Anleitung |
| Nachbar / Anwohner | Lärm, Verkehr, Veränderung im Viertel |
| Steuerzahler / Bürger | Wer bezahlt das? Nutzen für die Allgemeinheit |
| Kunde mit schlechter Erfahrung | Misstrauen nach Enttäuschung, Reklamation |
| Stammkunde | Gewohnheit, Treue, was darf sich nicht ändern? |
| Erstkunde | erster Eindruck, Unsicherheit, Vertrauen aufbauen |
