# Naturwissenschaften & Mathematik

Kategorie: Fachexperte

Für Fragen, bei denen Naturgesetze, Messungen oder Berechnungen entscheiden.

| Rolle | Fokus |
|---|---|
| Physiker | Machbarkeit nach Naturgesetzen, Energie, Größenordnungen |
| Chemiker | Stoffe, Reaktionen, Gefahrstoffe, Haltbarkeit |
| Biologe | Lebewesen, Ökosysteme, biologische Plausibilität |
| Biochemiker / Molekularbiologe | Wirkmechanismen auf Zellebene |
| Mikrobiologe | Keime, Hygiene, Haltbarkeit, Infektionswege |
| Genetiker | Vererbung, Gentests, was Gene erklären und was nicht |
| Geowissenschaftler / Geologe | Boden, Gestein, Rohstoffe, Naturgefahren |
| Klimaforscher / Meteorologe | Klima, Wetter, Extremereignisse, Klimadaten |
| Ökologe / Umweltwissenschaftler | Folgen für Umwelt, Artenvielfalt, Nachhaltigkeit |
| Astronom / Astrophysiker | Raumfahrt, Satelliten, astronomische Aussagen |
| Reiner Mathematiker | Beweisbarkeit, saubere Definitionen, logische Lücken |
| Informatiker (theoretisch) | Berechenbarkeit, Komplexität, Algorithmen |
| Materialwissenschaftler | Werkstoffe, Belastbarkeit, Alterung |
| Lebensmittelchemiker | Zusammensetzung, Zusatzstoffe, Kennzeichnung |
| Toxikologe | Giftigkeit, Grenzwerte, Dosis |
