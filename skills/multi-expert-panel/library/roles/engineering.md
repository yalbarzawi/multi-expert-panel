# Ingenieurwesen & Technik

Kategorie: Fachexperte

Für alles, was gebaut, konstruiert, betrieben oder zugelassen werden muss.

| Rolle | Fokus |
|---|---|
| Maschinenbauingenieur | Konstruktion, Mechanik, Fertigbarkeit |
| Elektroingenieur / Elektrotechniker | Schaltungen, Energieversorgung, Normen (VDE) |
| Bauingenieur / Statiker | Tragfähigkeit, Statik, Bauvorschriften |
| Verfahrenstechniker | Produktionsprozesse, Anlagen, Durchsatz |
| Produktionsingenieur / Fertigungsplaner | Stückkosten, Taktzeit, Serienfertigung |
| Automatisierungs- / Robotikingenieur | Steuerung, Sensorik, Automatisierbarkeit |
| Embedded- / Hardware-Entwickler | Platinen, Mikrocontroller, Firmware, Stromverbrauch |
| Nachrichtentechniker / Netzwerkingenieur | Funk, Netze, Bandbreite, Latenz |
| Energietechniker | Photovoltaik, Speicher, Netze, Wirkungsgrad |
| Fahrzeugingenieur | Fahrzeugtechnik, Zulassung, Sicherheit |
| Luft- und Raumfahrtingenieur | Gewicht, Zuverlässigkeit, Zertifizierung |
| Umweltingenieur | Emissionen, Abwasser, Recycling, Genehmigung |
| Medizintechniker | Medizinprodukte, MDR-Zulassung, Patientensicherheit |
| Wirtschaftsingenieur | Technik und Kosten zusammen, Beschaffung |
| Prüfingenieur (TÜV, DEKRA) | Normen, Prüfung, Zertifizierung, CE |
| Arbeitssicherheitsingenieur | Unfallgefahren, Gefährdungsbeurteilung |
| Industriedesigner | Form, Ergonomie, Herstellbarkeit |
| Patentingenieur | Erfindungshöhe, Stand der Technik, Patentierbarkeit |
| Wartungs- und Instandhaltungstechniker | Verschleiß, Ersatzteile, Ausfallzeiten |
