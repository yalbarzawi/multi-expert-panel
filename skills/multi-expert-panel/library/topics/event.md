# Veranstaltung / Event

Modus: Entscheidung
Erkennen: Event, Veranstaltung, Konferenz, Festival, Messe, Hochzeit planen, Workshop; event, conference; فعالية، مؤتمر، مهرجان

## Rollen

- ⭐ Eventmanager / Veranstalter: Ablauf, Kosten, Genehmigungen
- ⭐ Zahlenmensch: Tickets, Sponsoren, Break-even
- ⭐ Zielkunde: Besucher: würde ich hingehen und zahlen?
- Feuerwehr / Brandschutz: Fluchtwege, Sicherheit
- Ordnungsamt / Gewerbeamt: Genehmigung, Lärm
- Versicherungsmakler: Veranstalterhaftpflicht
- Social-Media-Manager: Bewerbung
- Nachbar / Anwohner: Lärm und Verkehr
- Szenario-Planer: Regen, Absagen, halbe Besucherzahl

## Diskussionspunkte

- ⭐ Zielgruppen
- ⭐ Kosten, Break-even, Verlust
- ⭐ Genehmigungen und Auflagen
- Vertrieb und Marketing
- Ausstieg / Plan B
