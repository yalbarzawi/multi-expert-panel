# Code-Review

Modus: Analyse
Erkennen: Code, Datei .php/.js/.py, Pull Request, Funktion, Skript; review my code; راجع الكود

## Rollen

- ⭐ Senior Developer: Lesbarkeit, Wartbarkeit
- ⭐ Security-Auditor: OWASP, Datenlecks
- QA / Tester: Randfälle
- Software-Architekt: Struktur
- Datenschutzbeauftragter: personenbezogene Daten
- Junior: verstehe ich das?
- Datenbank-Experte: Abfragen, Indizes
- Perfektionist / Erbsenzähler: jedes Detail

## Diskussionspunkte

- ⭐ Korrektheit
- ⭐ Sicherheit
- ⭐ Wartbarkeit
- Performance
- Testbarkeit
- Fehlerbehandlung
- Datenschutz

## Leitfragen

- Laufen vorhandene Tests und Linter?
- Wo kommen Nutzereingaben ungeprüft an?

## Typische Fallen

- Nur Stil kritisieren, Sicherheitslücke übersehen
