# Vom Fachgebiet zur Rolle

Für Themen ohne passendes Themenpaket: Fachgebiet erkennen, dann aus diesen Gruppen mischen. Immer mindestens eine Rolle aus `roles/research-analysis.md` anbieten, wenn Fakten, Zahlen oder Markt eine Rolle spielen. Passt kein Themenpaket, aber das Thema kommt oft vor: neues Paket in `topics/` anlegen (siehe README).

| Wenn es geht um … | Passende Rollen |
|---|---|
| Markt, Nachfrage, Konkurrenz | Researcher / Rechercheur, Wettbewerbsanalyst / Produktvergleicher, Volkswirt / Wirtschaftsanalyst, Konkurrent, Zielkunde |
| Geld, Preis, Rentabilität | Finanzanalyst, Zahlenmensch, Controller, Steuerberater, Investor / Business Angel |
| Förderung, Finanzierung | Gründungsberater (IHK), Bankberater / Kreditprüfer, Finanzanalyst |
| Zahlen, Statistik, Prognosen | Mathematiker / Statistiker, Datenanalyst, Szenario-Planer |
| Argumente, Behauptungen, Studien | Logiker / Argumentationsprüfer, Faktenprüfer, Wissenschaftler |
| Zukunft, Technologie, Trends | Trend- und Zukunftsforscher, CTO / technische Leitung, Seriengründer |
| Risiko, Recht, Missbrauch | Risikoanalyst, IT-/Medienrechtler, Wirtschaftsjurist / Vertragsrecht, Datenschutzbeauftragter, Red Team |
| Software, Daten, Betrieb | Software-Architekt, Senior Developer, Security-Auditor, DevOps / Admin |
| Marke, Gestaltung, Wirkung | Markenstratege, Art Director, UI-/UX-Designer, Ungeduldiger Leser |
| Menschen, Nutzung, Alltag | Endnutzer im Alltag, Laie, Nutzer mit Einschränkung, Partner / Familie |
| Gesundheit | Arzt (Allgemeinmedizin), Psychologe, Arbeitsmediziner |
| Bauen, Wohnen, Energie | Gutachter / Sachverständiger, Architekt, Handwerksmeister, Energieberater |
| Medizin, Behandlung, Pflege | Facharzt des Gebiets, Arzt (Allgemeinmedizin), Apotheker, Pflegefachkraft, Epidemiologe, Mensch mit chronischer Krankheit |
| Naturwissenschaft, Machbarkeit | Physiker, Chemiker, Biologe, Materialwissenschaftler, Professor / Lehrstuhlinhaber |
| Technik, Produkt, Erfindung | Maschinenbauingenieur, Elektroingenieur / Elektrotechniker, Prüfingenieur (TÜV, DEKRA), Patentanwalt, Industriedesigner |
| Forschung, Studium, Lehre | Professor / Lehrstuhlinhaber, Peer-Reviewer, Doktorand, Hochschuldidaktiker, Forschungsförderer (DFG, EU) |
| Gesellschaft, Kultur, Werte | Soziologe, Philosoph / Ethiker, Historiker, Kulturanthropologe / Ethnologe, Islamwissenschaftler |
| Staat, Behörden, Politik | Verwaltungsbeamter, Bürgermeister / Kommunalpolitiker, Richter, Fachanwalt Verwaltungsrecht, Lobbyist / Verbandsvertreter |
| Handwerk, Bau im Alltag | Elektriker, Installateur / Sanitär-Heizung-Klima, Maurer / Bauarbeiter, Handwerksmeister |
| Kunst, Medien, Events, Sport | Schriftsteller / Autor, Filmemacher / Regisseur, Eventmanager / Veranstalter, Sporttrainer, Podcaster / YouTuber |
| Der normale Mensch | passende Person aus everyday-people.md (Rentner, Student, Alleinerziehende, Neu in Deutschland …) |

Für jedes Fach lassen sich mit `levels.md` alle Stufen besetzen, vom Professor bis zum Laien.
