## [1.0.0] - 2026-11-07

First public release.

### Added
- Virtual expert panel for any decision or review, in two modes: analysis (critique, rewrites, score X/10) and decision (red-team pre-mortem, verdict GO / GO WITH CONDITIONS / PILOT / NO-GO).
- You choose the experts and the discussion points, or get suggestions for your topic.
- Library with 343 roles in 25 categories, 22 topic packs (including new department and product improvement), 89 discussion points, an 8-level expertise ladder and dated knowledge files with sources.
- Six output styles, including an HTML discussion log without a limit on panel size.
- Deep mode: up to 6 key experts review your case as independent parallel agents with their own web research.
- Discussion series: several sessions per project in one folder, with an overview page and a shared dossier.
- Any language for answers and the HTML log (built-in English, German, Arabic; right-to-left layout).
- Install as a Claude Code plugin, as a ZIP for claude.ai, or manually.
- Web and file content is treated as data, never as instructions.
